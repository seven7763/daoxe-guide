Доступ к Doubao API, OpenAI-совместимо — без ep- эндпоинтов

Doubao — семейство моделей ByteDance, обычно доступное через Volcengine Ark с провижинингом эндпоинтов. Через DaoXE вы это пропускаете и вызываете обычный ID модели по одному ключу.

Обновлено 2026-07-20

Нативно Volcengine Ark требует создать инференс-эндпоинт и вызывать ID вида ep-…. Через DaoXE Doubao за тем же OpenAI-совместимым ключом, что GPT, Claude и DeepSeek — вы вызываете обычный каталожный ID из GET /v1/models, без консоли Volcengine. Маршрутизация — гайд по дешёвым API.

Как вызвать Doubao через DaoXE#

Используйте /v1/chat/completions с точным ID Doubao из GET /v1/models. Шага провижининга здесь нет: каталожный ID заменяет нативный ep-…. Рассуждениями управляет нестандартное поле thinking (enabled/disabled/auto), цепочка рассуждений приходит в reasoning_content, а reasoning_effort масштабирует глубину размышления. Vision-варианты принимают изображения через OpenAI-стиль content parts.

bash
# Doubao (Volcengine Ark) natively wants endpoint IDs like "ep-2024...".
# Through DaoXE you use the catalog model ID from GET /v1/models instead —
# no endpoint provisioning, no separate Volcengine console.
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Reply with OK."}]
  }'

Как Doubao/Seed отдаёт рассуждения#

Цепочка рассуждений Ark приходит в choices.message.reasoning_content — на thinking-summary моделях это сводка размышлений, а сырая трасса едет рядом блобом encrypted_content. В многошаговых tool-циклах возвращайте блоб (приоритет выше) или сводку; на версиях с doubao-seed-1.8 сохранённый reasoning_content по решению модели участвует в рассуждениях, а токены невидимого модели контента не тарифицируются. Между обычными ходами CoT в контекст не вклеивается — сохраняется только в раундах с tool calls. Управляют им поле thinking (enabled/disabled/auto) и семиступенчатая лестница reasoning_effort с пофамильными дефолтами и правилами ремапа — какие из этих нестандартных полей проходит конкретный путь релея, ровно то, что надо проверять: один тестовый вызов, прежде чем привязывать клиент.

Нюансы именно для Doubao#

  • Никаких ep- ID. Не вставляйте строку Volcengine ep-…; используйте каталожный ID из GET /v1/models.
  • У поля thinking три состояния. enabled принудительно включает цепочку рассуждений, disabled глушит её, auto решает сама модель — поле нестандартное, отправляйте через extra-body вашего SDK. Для текущих reasoning-ID doubao-seed вендор указывает enabled как состояние по умолчанию.
  • Вернётся сводка, а не сырая трасса. На thinking-summary моделях вендор возвращает сводку в reasoning_content плюс блоб сырых размышлений в encrypted_content. Правила истории делятся по версиям: до 251228 — вычищайте reasoning_content; doubao-seed-1.8 и новее — сохраняйте, модель сама решит. В tool-циклах возвращайте encrypted_content (приоритет выше) или сводку — потеря обоих ухудшает следующий ответ.
  • Уровни effort и бюджет вывода. reasoning_effort идёт от none до max, но каждая модель перераспределяет вне-диапазонные значения по-своему (дефолт high уровня Seed-2.1 мапит max→high; дефолт medium уровня Seed-2.0 мапит low/medium→high). И max_tokens лимитирует только ответ — когда мышление должно делить бюджет, берите max_completion_tokens. Точные ID — всегда из GET /v1/models.

Сколько это стоит#

Один баланс, один курс пополнения

Пополнение идёт по фиксированному курсу 1 ¥ = $1 квоты любым способом оплаты, а каждая модель тарифицируется по своей цене в USD — актуальные цены по моделям смотрите на daoxe.com/pricing. Курс одинаковый для всех способов оплаты: Alipay, WeChat Pay, USDT, банковская карта (Visa · Mastercard), Apple Pay и Google Pay — один баланс на все модели каталога, без выбора тарифа и без месячного минимума. Цены зависят от аккаунта и меняются, поэтому проверьте небольшим пополнением, а не доверяйте цифре из гайда.

Убедитесь, что отдают настоящую модель#

Сначала проверьте эндпоинт, а не клиент — если это не работает, настройки не помогут:

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

Частые вопросы#

Нужен ли аккаунт Volcengine или ep- эндпоинт?

Нет — через DaoXE Doubao за вашим единым ключом с обычным каталожным ID; шага провижининга нет.

Как включить или выключить мышление?

Отправьте нестандартное поле thinking: enabled принудительно включает цепочку, disabled глушит, auto решает модель. У текущих reasoning-ID doubao-seep дефолт — enabled.

Почему рассуждения — сводка, а не сырая трасса?

На thinking-summary моделях Ark возвращает сводку в reasoning_content плюс сырые размышления в encrypted_content. В tool-циклах возвращайте блоб (или сводку) — потеря обоих ухудшает следующий ответ.

Сколько стоит Doubao здесь?

По модели и аккаунту — см. актуальные цены. Пополнение — фиксированные 1 ¥ = $1 квоты любым способом оплаты.
