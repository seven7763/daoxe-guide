在 LibreChat 里用 DaoXE

LibreChat 是自托管的多模型聊天 UI。它的 endpoints.custom 块接受任何 OpenAI 兼容端点 —— 一条 DaoXE 配置就能让实例上每个用户用上整个账号目录。

更新于 2026-07-20

LibreChat 由 librechat.yaml 配置。在 endpoints.custom 下声明 name、apiKey 和 baseURL —— 正是 DaoXE 的形态。models 子块决定用户能选什么，而且 LibreChat 还能直接从 GET /v1/models 实时拉取（最便宜 API 教程）。

为什么让 LibreChat 走 DaoXE#

  • 自托管、多用户。 一条 YAML 条目服务整个实例；key 留在服务端，不进浏览器。
  • 声明式模型。 列出精确 ID，或设 models.fetch: true 从账号拉实时列表。
  • 按端点调优。 标题生成、参数注入与剔除都是端点级字段。

在 LibreChat 里配置#

  1. 编辑 librechat.yaml。 打开 librechat.yaml（docker-compose 挂载的那份），在 endpoints.custom 下加一个块。
  2. name、key、baseURL。 name: "DaoXE"；apiKey: "{DAOXE_API_KEY}"（env 引用让 key 不进文件）；baseURL: "https://daoxe.com/v1"。
  3. 声明模型。 models.default 列 GET /v1/models 的精确 ID；加 models.fetch: true 可同时拉实时列表。拉取失败时 default 作为回退。
  4. 重启并选择。 重启 LibreChat，端点选择器里选 DaoXE，模型选择器里选模型，发条测试消息。
yaml
# librechat.yaml — custom OpenAI-compatible endpoint
endpoints:
  custom:
    - name: "DaoXE"
      apiKey: "${DAOXE_API_KEY}"
      baseURL: "https://daoxe.com/v1"
      models:
        default: ["YOUR_EXACT_MODEL_ID"]
        fetch: true
      titleConvo: true
      titleModel: "current_model"

值得注意的坑

baseURL 到 /v1 为止：应用自己补 /chat/completions；如果给完整路径则需要 directEndpoint: true 才会原样使用。titleModel：对话标题默认用 gpt-3.5-turbo 生成，你的 key 未必有它 —— 把 titleModel 设成目录里的真实 ID（或 current_model），否则标题生成会失败。别用内置名：自定义端点叫「openAI」「anthropic」会和内置冲突 —— 想要图标用 iconURL 指向内置键。addParams / dropParams：按端点注入或剔除请求参数的字段 —— 端点拒绝某个默认参数时用 dropParams。模型 ID 与账号绑定。更多客户端见客户端设置说明。

验证你拿到的是真模型#

先证明端点可用，再怀疑客户端 —— 这一步失败，改任何设置都没用：

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

先在 LibreChat 之外验证端点，再在 temperature 0 下把难题与官方 API 对比：

bash
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'

常见问题#

LibreChat 能接 DaoXE 吗？

能 —— 一条 endpoints.custom：baseURL: https://daoxe.com/v1、env 引用的 key、精确模型 ID。

为什么对话标题生成失败？

默认 titleModel 是 gpt-3.5-turbo，你的 key 可能调不到。设成 GET /v1/models 里的真实 ID 或 current_model。

baseURL 要带 /v1 吗？

要 —— LibreChat 自己补 /chat/completions。只有给了完整路径才需要 directEndpoint: true。

怎么收费？

按模型、随账号 —— 实时定价；充值统一 1 元 = $1 额度。
