在 SillyTavern 里用 DaoXE

SillyTavern 是面向重度用户的 LLM 前端。它的 Chat Completion 源「Custom (OpenAI-compatible)」接受任何 OpenAI 形态端点 —— 一个 DaoXE key 就能驱动角色聊天、群聊和世界书工作流，模型来自整个账号目录。

更新于 2026-07-20

SillyTavern 通过 Chat Completion → Custom (OpenAI-compatible) 接入网关：一个 Custom Endpoint (Base URL)、key 和模型 ID。界面自己就提示了两个经典错误 —— 漏掉 /v1 和手动补 /chat/completions —— 所以动手前先看完下面的配置（最便宜 API 教程）。

为什么让 SillyTavern 走 DaoXE#

  • 为深度定制而生。 角色卡、世界书、instruct 模板、群聊，全跑在一个端点上。
  • 一个 key，多家厂商。 不同对话换模型 ID，端点不动。
  • 服务端代理。 Node 服务器转发请求 —— CORS 永远不会拦浏览器调用。

在 SillyTavern 里配置#

  1. 打开 API Connections。 顶部 插头 图标 → API Connections。API 选 Chat Completion。
  2. 选 Custom 源。 Chat Completion Source 选 Custom (OpenAI-compatible)。
  3. 填端点和 key。 Custom Endpoint (Base URL) 填 https://daoxe.com/v1 —— 不要加 /chat/completions，ST 会自己补。DaoXE key 填在 Custom API Key。
  4. 选模型、连接、测试。 在 Enter a Model ID 里填 GET /v1/models 的精确 ID（下拉能填充就直接选），点 Connect，再跑 Test Message 检查。

值得注意的坑

/v1 规则两头都要对：ST 会在你填的地址后补 /chat/completions —— UI 提示原话是「Doesn't work? Try adding /v1 at the end!」并明说后缀自动添加。裸填 https://daoxe.com 会 404；正确写法到 /v1 为止。Prompt post-processing：如果聊天报角色/顺序错误（有些 OpenAI 形态服务器只接受严格交替的消息），设置 Custom Prompt Post-Processing —— Strict 或 Semi-strict 变体会重写历史。工具调用：标着「no tools」的变体会剥掉工具调用 —— 模型支持 function calling 就用 with-tools 变体。Bypass API status check 是给「端点正常但状态探测失败」的场景 —— 重写 URL 之前先试它。用 GET /v1/models 的精确 ID；猜的名字第一条消息就会失败。更多客户端见客户端设置说明。

验证你拿到的是真模型#

先证明端点可用，再怀疑客户端 —— 这一步失败，改任何设置都没用：

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

先在 ST 之外验证端点，再在 temperature 0 下把难题与官方 API 对比：

bash
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'

常见问题#

SillyTavern 能接 DaoXE 吗？

能 —— Chat Completion → Custom (OpenAI-compatible)：Base URL 填 https://daoxe.com/v1，加 key 和精确模型 ID。

URL 里要加 /chat/completions 吗？

不要 —— SillyTavern 自动补。Base URL 到 /v1 为止；手动补后缀是最常见的 404 原因。

模型列表拉不下来怎么办？

直接在 Enter a Model ID 里手填。列表拉取失败时 ST 会回退到文本框；如果端点本身正常，Bypass API status check 能消掉警告。

怎么收费？

按模型、随账号 —— 实时定价；充值统一 1 元 = $1 额度。
