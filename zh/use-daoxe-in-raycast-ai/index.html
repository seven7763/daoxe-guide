在 Raycast AI 里用 DaoXE

Raycast 启动器内置 AI 聊天、Quick AI 和 AI Extensions。它的 Custom Providers 通过一个 YAML 文件接受任何 OpenAI 兼容端点 —— 一个 DaoXE key 喂饱启动器里的所有 AI 入口。

更新于 2026-07-20

Raycast 的 Custom Providers 读取 ~/.config/raycast/ai/providers.yaml，把你声明的模型注册进所有 AI 功能 —— 聊天、Quick AI、AI Extensions。加一条 DaoXE 记录，启动器的模型选择器就能在一个余额里覆盖 GPT、Claude、Gemini、DeepSeek 和你账号的整个目录（最便宜 API 教程）。

为什么让 Raycast AI 走 DaoXE#

  • AI 在按键层。 Raycast 要模型的地方都是同一批 —— 不用来回切应用。
  • 一个 key，多家厂商。 跨厂商网关是官方明确支持的形态，不是偏方。
  • 直连路由。 请求从你的设备直达端点 —— Raycast 的服务器不在链路里。

在 Raycast AI 里配置#

  1. 打开 Custom Providers。 Raycast → Settings → AI → 滚到 Custom Providers → Reveal Providers Config。把 providers.template.yaml 复制成 providers.yaml。
  2. 声明供应商。 加一条记录：base_url: https://daoxe.com/v1（不要带 /chat/completions 后缀），key 放 api_keys。
  3. 注册精确模型 ID。 每个模型要有从 GET /v1/models 原样复制的 id、显示用 name、符合实际的 context。猜的 ID 在请求时才失败。
  4. 如实声明 abilities。 声明模型真实支持的能力 —— AI Extensions 需要 tools，图片输入需要 vision。保存即热加载，不用重启。
yaml
# ~/.config/raycast/ai/providers.yaml
providers:
  - id: daoxe
    name: DaoXE
    base_url: https://daoxe.com/v1
    api_keys:
      daoxe: sk-you…-key
    models:
      - id: <exact-model-id>
        name: GLM 5.3 Flash
        provider: daoxe
        context: 128000
        abilities:
          tools: {supported: true}
          vision: {supported: true}

值得注意的坑

需要 Pro。 Custom Providers 是 Pro 档功能，免费档没有这个区块。默认能力会咬人：没声明的能力默认 system-message 和 temperature 开、tools 和 vision 关 —— 本来会工具调用的模型被静默阉割。校验徽标：YAML 写错时 Settings 里出现 Invalid providers.yaml 徽标，悬停看解析错误；修好之前已加载的模型照常工作。OpenAI API 不是标准：Raycast 文档明说无法保证所有供应商都兼容 —— 全面铺开前先测一条聊天。更多客户端见客户端设置说明。

验证你拿到的是真模型#

先证明端点可用，再怀疑客户端 —— 这一步失败，改任何设置都没用：

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

先在客户端之外验证端点，再在 temperature 0 下把难题与官方 API 对比：

bash
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'

常见问题#

Raycast AI 能接 DaoXE 吗？

能 —— Custom Providers：在 providers.yaml 加一条 base_url: https://daoxe.com/v1，配上 key 和精确模型 ID。

需要 Raycast Pro 吗？

Custom Providers 需要。免费档的 AI 看不到这个区块。

为什么模型的 tools 不工作？

tools 和 vision 默认关闭 —— 只有模型真支持时才声明 supported: true。

怎么收费？

按模型、随账号 —— 实时定价；充值统一 1 元 = $1 额度。

试用 DaoXE —— 并亲自 benchmark 它

一个 key 调 GPT、Claude、Gemini、DeepSeek 等。用开源 benchmark 对准我们做对比 —— 别只听我们说。
