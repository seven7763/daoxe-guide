在 NextChat 里用 DaoXE

NextChat（前身 ChatGPT-Next-Web）是可自托管的聊天 UI，其 OpenAI 供应商接受自定义端点。指到 DaoXE，一个 key 就能喂满它的模型选择器。

更新于 2026-07-20

NextChat 说 OpenAI 兼容 HTTP，所以接 DaoXE 就是换端点 —— 设置界面里改，或自托管时设 OPENAI_BASE_URL。再用 CUSTOM_MODELS 精确控制哪些账号级 ID 出现在选择器里（最便宜 API 教程）。

为什么让 NextChat 走 DaoXE#

  • 几分钟自托管。 Docker + 两个环境变量，对话数据留在自己服务器。
  • 选择器即你的目录。 CUSTOM_MODELS 白名单（或 - 前缀隐藏）来自 GET /v1/models 的真实 ID。
  • 一个 key 喂整个实例。 你部署的 NextChat 所有用户共享一个 DaoXE 余额。

在 NextChat 里配置#

  1. 官方托管版：设置。 设置 → 模型服务商 → OpenAI：粘贴 DaoXE key，API 地址填 https://daoxe.com/v1。
  2. 自托管：环境变量。 docker-compose / Vercel 里设 OPENAI_API_KEY 与 OPENAI_BASE_URL=https://daoxe.com/v1。
  3. 整理模型列表。 CUSTOM_MODELS 填精确 ID；调不通的内置项用 - 前缀隐藏。
  4. 发条测试消息。 再核对响应里的 model 字段就是你选的那个 ID。
bash
# self-hosted: docker-compose env
OPENAI_API_KEY=sk-you…-key
OPENAI_BASE_URL=https://daoxe.com/v1
CUSTOM_MODELS=glm-5.3-flash,-gpt-4o

值得注意的坑

OPENAI_BASE_URL 到 /v1 为止 —— NextChat 自己补 /chat/completions，缺后缀就是经典 404。你 key 调不通的内置模型名必须用 CUSTOM_MODELS=-名字 隐藏，否则选择器里全是死项。server-side 与 client-side 模式决定 key 放在哪 —— 共享部署务必放服务端。更多客户端见客户端设置说明。

验证你拿到的是真模型#

先证明端点可用，再怀疑客户端 —— 这一步失败，改任何设置都没用：

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

先在 UI 之外验证端点，再在 temperature 0 下把难题与官方 API 对比：

bash
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'

常见问题#

NextChat 能接 DaoXE 吗？

能 —— 就是换 OpenAI 端点：key + https://daoxe.com/v1，设置界面或 OPENAI_BASE_URL 都行。

为什么选择器里有些模型报错？

那些是你 key 调不通的内置名。用 CUSTOM_MODELS=-gpt-4o,… 隐藏，只留 GET /v1/models 里的 ID。

自托管还是 Vercel？

同一套环境变量。对外共享的部署把 key 留在服务端（API 模式），别暴露进访客浏览器。

费用？

按模型、随账号 —— 实时定价；充值统一 1 元 = $1 额度。

试用 DaoXE —— 并亲自 benchmark 它

一个 key 调 GPT、Claude、Gemini、DeepSeek 等。用开源 benchmark 对准我们做对比 —— 别只听我们说。
