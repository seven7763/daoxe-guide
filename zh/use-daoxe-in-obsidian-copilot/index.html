在 Obsidian Copilot 里用 DaoXE

Copilot 是 Obsidian 安装量最大的 AI 插件。它的 BYOK 流程接受任何 OpenAI 兼容端点作为自定义供应商 —— 一个 DaoXE key 就能让笔记库聊天与 agent 功能变成多厂商配置。

更新于 2026-07-20

Copilot 的 Settings → Copilot → BYOK → Add a provider → Add a custom provider 只要 base URL、key 和模型 ID —— 这正是 DaoXE 的形态。配一次，Quick Chat 和 agent 功能就能在一个余额里触达 GPT、Claude、Gemini、DeepSeek 和你账号目录里的其余模型（最便宜 API 教程）。

为什么让 Obsidian Copilot 走 DaoXE#

  • AI 在笔记旁边。 聊天、改写、总结直接对着笔记库，不用把文字搬到别的应用。
  • 一个 key，多家厂商。 插件里不用塞各家账号。
  • key 存在 Keychain。 BYOK key 存在本设备的 Obsidian Keychain，不进笔记库的 data.json —— 同步笔记库不会带走凭证。

在 Obsidian Copilot 里配置#

  1. 打开 BYOK 设置。 Obsidian → Settings → Copilot → BYOK → Add a provider → Add a custom provider。
  2. 填 base URL 和 key。 填 https://daoxe.com/v1 和你的 DaoXE key。base URL 到 /v1 为止，路径插件自己补。
  3. 填精确模型 ID。 模型发现走端点的 /v1/models；如果列表拉不下来，就从 GET /v1/models 原样粘贴一个 ID —— 猜的名字会失败。
  4. Test 后整理列表。 点 Test 和 Save。新模型默认对 Quick Chat 和 agent 功能启用；列表在 Basic → Agents 里整理。

值得注意的坑

CORS 开关：如果 Test 通过但聊天发不出去，编辑供应商并打开 Enable CORS —— 之后响应会在完成后整体到达，而不是逐 token 流式。Agent 路由：Copilot 在启动时把保存的 key 传给 agent 后端；后端路由不了的模型不会出现在 agent 列表，但仍可能用于 Quick Chat。key 存储：key 在本设备 Keychain，删除入口在 Advanced → API Key Storage。模型 ID 与账号绑定。更多客户端见客户端设置说明。

验证你拿到的是真模型#

先证明端点可用，再怀疑客户端 —— 这一步失败，改任何设置都没用：

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

先在客户端之外验证端点，再在 temperature 0 下把难题与官方 API 对比：

bash
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'

常见问题#

Obsidian Copilot 能接 DaoXE 吗？

能 —— BYOK → Add a custom provider：base URL 填 https://daoxe.com/v1，加 key 和精确模型 ID。

Test 通过但聊天失败？

这是 CORS 情形：在供应商设置里开 Enable CORS。之后响应改为非流式整体返回。

key 存在哪？

本设备的 Obsidian Keychain —— 不在 data.json 里，所以同步笔记库不会复制 key。

怎么收费？
