在 BoltAI 里用 DaoXE

BoltAI 是 macOS 原生 AI 客户端，带 inline 和命令模式。它的「OpenAI-compatible Server」供应商接受任何 OpenAI 形状的端点 —— DaoXE 用一个 URL 就能接上。

更新于 2026-07-20

BoltAI 内置多家供应商（OpenAI、Anthropic、OpenRouter……），但通用的逃生口是 Settings → Models 里的 OpenAI-compatible Server 类型。DaoXE 说这种格式，所以一条配置就覆盖整个目录（最便宜 API 教程）。

为什么让 BoltAI 走 DaoXE#

  • macOS 原生、处处可用。Chat、AI Command 和 AI Inline 共用同一个供应商 —— 一把 DaoXE key 就能驱动任何应用里的快捷操作。
  • 一个 key、多模型。在聊天配置弹层里切换模型，不必在各个厂商账号之间腾挪。
  • 本地与云端同台。BoltAI 的 Ollama 支持和 DaoXE 供应商条目共用一个模型选择器。

在 BoltAI 里配置#

  1. 打开供应商表单。 进入 Settings → Models，点 (+) 按钮并选择 OpenAI-compatible Server。
  2. 名称与 endpoint。 起个友好名称，然后粘贴精确的 chat completions URL：https://daoxe.com/v1/chat/completions。BoltAI 官方指南要求「输入 chat completions 端点的精确 url」—— 它给 LM Studio 的示例就是 http://localhost:1234/v1/chat/completions。
  3. 模型 ID 与上下文。 填会随请求作为 model 参数发送的模型 ID（每条配置一个默认值 —— 从 GET /v1/models 照抄精确 ID），再按模型文档填上下文长度。
  4. 流式、默认、保存。 需要就打开流式；点 Save Changes。BoltAI 文档特别标注了最后一步：「如果不打算用 OpenAI，务必把它设为默认」。

值得注意的坑

endpoint 是完整路径：与多数客户端不同，BoltAI 的 OpenAI-compatible 表单要的是带 /chat/completions 的完整 URL，不是 base URL —— 只给 /v1 在这里行不通。一条配置一个模型：表单只收一个模型 ID（它「会随每次请求发送」）；要多模型就多加几条配置。上下文长度自己负责：文档要求「参考原始模型」——填错要么浪费预算要么截断输出。默认服务很关键：自定义服务器上的 AI Command 是 beta，只有把该服务器设为默认 AI 服务才会生效。钥匙串弹窗：key 存在 Apple Keychain —— 如果不再持久化，去钥匙串访问里重新授权 BoltAI（条目 BoltAI_openAIKey）。更多客户端见客户端设置说明。

验证你拿到的是真模型#

先证明端点可用，再怀疑客户端 —— 这一步失败，改任何设置都没用：

bash
export DAOXE_API_KEY="your_api_key"

# List the exact model IDs your account can call
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/models \
  -H "Authorization: Bearer ${DAOXE_API_KEY}"

先在应用之外验证端点，再在 temperature 0 下把难题与官方 API 对比：

bash
curl --fail-with-body --show-error --silent \
  https://daoxe.com/v1/chat/completions \
  -H "Authorization: Bearer ${DAOXE_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_EXACT_MODEL_ID",
    "max_tokens": 64,
    "messages": [{"role": "user", "content": "Say hello in one sentence."}]
  }'

常见问题#

BoltAI 能接 DaoXE 吗？

能 —— Settings → Models → (+) → OpenAI-compatible Server，URL 填 https://daoxe.com/v1/chat/completions 加 DaoXE key。

填 base URL 还是完整端点？

完整端点 —— BoltAI 要的是精确的 chat completions URL（…/v1/chat/completions），这与多数收 base URL 的 OpenAI 兼容客户端不同。

为什么自定义服务器在 AI Command 里不生效？

BoltAI 文档标注自定义服务器上的 AI Command 为 beta：把 OpenAI-compatible 条目设为默认 AI 服务，否则命令仍走旧供应商。
